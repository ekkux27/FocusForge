# FocusForge - Student Command Center

A minimal, dark-themed productivity dashboard designed to help students organize daily tasks, track progress, and stay focused with a Pomodoro timer.

## Features

- **Task Management:** Add, complete, undo, and delete tasks.
- **Progress Tracking:** View total tasks, completed tasks, and completion percentage.
- **Persistent Storage:** Save tasks in browser LocalStorage.
- **Pomodoro Timer:** Focus and break sessions with start, pause, resume, and reset controls.
- **Responsive UI:** Adaptable layout for desktop and mobile screens.
- **Dark Theme:** Minimal interface with lime-green accents.

## Tech Stack

- HTML5
- CSS3 — Grid, Flexbox, media queries, transitions
- Vanilla JavaScript
- Browser LocalStorage API

## Getting Started

### 1. Clone the repository

```bash

```

### 2. Open the project


Open `index.html` in your browser, or use the Live Server extension in VS Code.

No package installation or build tools are required.
